## Summary

Given a set of non-overlapping circular districts on a plane, find the minimum number of district borders you'd have to cross to travel between two given points.

## Parameters

| Name | Type | Description |
|---|---|---|
| `x`, `y` | `int[]` | Center coordinates of each circular district. |
| `r` | `int[]` | Radius of each district. |
| `x1`, `y1` | `int` | Starting point coordinates. |
| `x2`, `y2` | `int` | Destination point coordinates. |

## Returns

`int` — the minimum number of district borders that must be crossed to get from the start point to the destination point.
