## Summary

Abbreviate a lowercase message (words separated by spaces) using a text-message-style shorthand: vowel-only words are left alone, and words with consonants get compressed to just their non-repeated consonant sounds, with vowels dropped.

## Parameters

| Name | Type | Description |
|---|---|---|
| `original` | `String` | The message to abbreviate (lowercase letters and spaces only). |

## Returns
