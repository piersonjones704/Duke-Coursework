## Summary

Given same-day entrance logs from three club locations, identify which members checked in at more than one location that day (against the rules), and return their names sorted alphabetically.

## Parameters

| Name | Type | Description |
|---|---|---|
| `club1`, `club2`, `club3` | `String[]` | Entry logs (member names) for each of the three locations. |

## Returns

`String[]` — the names of members who visited more than one location, sorted alphabetically, each listed once.
