## Summary

Given a pool of letters cut from several headlines, determine how many candidate messages could be spelled out using those letters (case-insensitive, spaces ignored, each candidate message checked independently).

## Parameters

| Name | Type | Description |
|---|---|---|
| `headlines` | `String[]` | The headlines whose letters are available to use. |
| `messages` | `String[]` | The candidate messages to check. |

## Returns

`int` — the number of candidate messages that can be fully spelled using the available letters.
