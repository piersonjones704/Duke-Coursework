## Summary

Score a player's remembered words against a dictionary of valid words. Each distinct word the player got right (i.e., it's in the dictionary) scores points based on its length; duplicates in the player's list only count once.

## Parameters

| Name | Type | Description |
|---|---|---|
| `player` | `String[]` | The words the player remembered (may contain duplicates). |
| `dictionary` | `String[]` | The list of valid, distinct words. |

## Returns

`int` — the player's total score.
